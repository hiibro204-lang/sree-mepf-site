# SREE ENGINEERING - MEPF website

Static multi-page site (HTML + CSS, no build step, no external dependencies except Google Fonts).

## Pages
- index.html - home
- about.html - practice and approach
- services.html - four divisions and scope matrix
- electrical.html, mechanical.html, plumbing.html, fire.html - division scope pages
- capabilities.html - voltage range, equipment chain, testing, compliance
- industries.html - sectors
- why-sree.html - the case for one accountable MEPF contract
- contact.html - enquiry

## Editing
Open any .html file; the shared design lives in assets/style.css. Colours, fonts and the wordmark match
the existing SREE ENGINEERING identity: Poppins display, Roboto body, JetBrains Mono labels, with the
blue / red / orange brand gradient on charcoal.

Deployed with GitHub Pages (workflow build).
